# 息壤 · 注意力训练与专注启动实验室

0.4.4 在本地混合检索之上增加平台无关的引用式 RAG 管线：固定上下文预算，为每条证据分配 `S1`～`S8` 可追溯引用，标记知识文档中的疑似提示注入，并严格校验生成结果只能引用本次提供的证据。设置页支持 Windows DPAPI 当前用户加密保存 DeepSeek Key，重启后自动加载，且浏览器和状态接口均不能读回明文。12 条真实 DeepSeek 固定评测覆盖正常回答、证据不足、冲突证据与提示注入，结构合法率、拒答准确率、引用正确率、确定性忠实度代理和注入抵抗率均为 100%；P50 为 10.816 秒，P95 为 13.214 秒。

0.4.3 完成可真实运行、可消融评测的本地混合检索链路：BM25 与 `BAAI/bge-small-zh-v1.5` 分别召回前 20 条，使用 RRF 融合，再可选用本地量化多语言 Cross-Encoder 重排前 12 条。设置页可在关键词、向量、混合和重排四种模式间切换，并查看双路排名、向量相似度、RRF 分数、重排分数与名次变化。项目使用 15 份真实项目文档和 100 条人工标注查询，固定划分 20 条开发集与 80 条保留测试集；最终重排模式在保留集达到 Recall@1 0.4533、Recall@5 0.7933、MRR@5 0.5891、nDCG@5 0.6383、拒答准确率 1.0000。

0.4.2 增加本地 BGE 语义召回和 Qdrant local mode 向量索引，支持 SHA-256 语料指纹、增量同步、过期索引阻断和显式清除。模型只从固定提交加载，权重会校验 SHA-256。

0.4.1 将起步样例扩展为真实项目文档评测集，补充同义改写、跨章节、相似章节、否定、错别字和域外问题，并新增 Recall@1/5、MRR@5、nDCG@5、拒答准确率及 P50/P95 延迟报告。

0.4.0 新增首个可运行的 RAG 检索基线：设置页中的“检索实验台”会把已授权知识文本块发送给本机 FastAPI 服务，通过 Jieba 中文分词和 BM25 完成关键词检索，并展示命中词、标题/章节加权、短语匹配、查询覆盖度、原文行号及服务端耗时。

0.3.7 扩展个人知识库文档识别：新增 Word DOCX 和文字型 PDF 导入。DOCX 使用 Mammoth 在浏览器或 Electron 内提取标题、段落、列表与表格，并转为可分块的结构化正文；PDF 使用 Mozilla PDF.js 按页读取文字层，保留总页数和“第 N 页”章节位置。提取正文继续接入现有 SHA-256 增量检测、300～700 字分块、预览、更新和级联删除流程；原始二进制文件不会存入知识库。DOCX/PDF 单文件限制为 10 MB，提取正文限制为 4 MB。扫描型或没有文字层的 PDF 当前不做 OCR，会明确提示用户。本阶段仍未加入关键词检索、向量或 AI。主应用格式继续使用 v10，知识库继续使用 IndexedDB v2。

0.3.6 完成 AI / RAG 数据基础的第三部分“文本处理”：TXT、个人笔记和 Markdown 知识来源会在本机提取正文，并按 Markdown 标题、自然段及长度边界生成可追溯文本块；常规文本块约 300～700 个字符，短章节会保持独立，避免跨章节混合。每块保存资料名称、完整章节路径、原文行号、字符位置、内容哈希和处理器版本。设置页可查看每份资料的文本块数量并预览分块结果。系统以知识来源 SHA-256 判断变化：内容未变时复用原文本块；只在某份资料发生变化、缺少文本块或处理器版本升级时重建该资料。当前仍未实施关键词检索、向量、RAG 查询或 AI 调用。主应用数据格式继续使用 v10，知识库继续使用 IndexedDB v2。

0.3.5 完成个人知识库的第二部分“知识存储”：独立 IndexedDB 升级为 v2，将知识来源、授权记录、文本块、检索记录和数据库元数据拆分到 5 个对象仓库；写入来源时使用 Web Crypto 生成 SHA-256 内容校验值，正文变化会使该来源的旧文本块失效，移除来源与清空设备数据会通过事务同步清理关联记录。0.3.4 的旧库会在首次读取时自动迁移并补齐授权与校验信息。设置页新增存储结构和各类记录数量状态；本阶段只完成可供后续使用的数据结构，尚未实施文本分块、检索、向量生成或 AI 调用。主应用数据格式继续使用 v10。

0.3.4 完成个人知识库管理的第一阶段：在“设置 → AI 与知识库”中管理知识来源，个人笔记默认不授权，可逐篇加入、取消或在原文变化后同步最新快照；同时支持导入、查看、更新和移除 TXT、MD、Markdown 文档。知识正文保存在独立的本地 IndexedDB，页面显示来源数量、授权笔记、导入文档和占用空间；当前没有文本分块、检索、向量或 AI 调用，现有 JSON 备份也暂不包含知识库文档。主应用数据格式继续使用 v10。

0.3.3 在“数据”页新增“行动洞察”：按近 7 天、近 30 天或全部范围，汇总待办进入行动的比例、开始前抗拒、现实专注完成度、下一步保留率、直接开始与启动舱路径、分心来源、最近续接入口及超过 7 天未更新的待办。所有观察都由本地固定规则生成，并明确显示样本量；它只描述个人历史记录，不判断因果或宣称某种方法一定有效。数据格式继续使用 v10，无需迁移。

0.3.2 将“便签”整理为“笔记 / 待办”两个子版块：笔记用于保存标题和自由正文，支持新建、搜索、编辑与移除；待办沿用行动便签的低摩擦记录方式，并提供勾选完成、重新打开、搜索、直接专注和拆成第一步。两类内容都保存在本机，待办继续与启动舱、现实专注及下一步记录保持关联；今日页和设置页同步显示笔记、待办及 v10 数据边界。

0.3.1 新增独立“行动便签”版块：用户只需写下一句话，就可以先放入收集区、直接开始现实专注，或进入启动舱把它拆成第一步。便签页支持搜索、编辑、待处理、已完成、重新放回和自动行动记录；今日页只保留一张简洁提示卡，不打断原有“启动—训练—现实专注”层级。便签与启动回合、现实专注和可选的“下一步”自动关联，不要求分类、优先级、日终整理或额外反馈。

0.3.0 新增“专注启动舱”，优先解决两种现实场景：已经知道要做什么却迟迟不愿开始，以及同时面对多件事、不知道现在先做什么。

用户可以直接输入一个明确任务，也可以放入最多三件候选任务，由完全本地、可解释的规则根据重要性、紧迫性和容易启动程度给出推荐。选定任务后，需要把它缩小为“第一个可以立刻执行的动作”和“本轮完成标准”，随后可以直接进入现实专注，或先完成一次可跳过的 60 秒启动热身。

启动热身不计入正式训练、不影响自适应难度，也不会进入训练趋势。启动回合与最终现实专注通过本地标识关联。个人专注配方已暂缓，未来可能结合个人数据、结构化查询、RAG 与 AI 生成专项计划；当前版本不生成因果结论或“最有效方法”判断。

第一版把注意力任务、现实专注和个人趋势放在同一条使用路径中：

1. 通过舒尔特方格、Go/No-Go 和 Stroop 建立个人基线；
2. 使用舒尔特方格、信号监测、反应抑制、抗干扰和约 5 分钟混合训练包进行短训练；
3. 在现实专注室中完成真正的学习或工作目标；
4. 在数据页查看训练正确率、反应速度和专注时间趋势。

“今日”页使用本地规则生成个性化计划：综合初始测评、最近 10 次表现、个人目标和前一天组合；近期表现波动时自动降低训练量，也可手动切换“状态不好”或“只有 5 分钟”模式。

训练中心支持从现有任务派生的多种形式：舒尔特可选择 4×4～6×6、数字、字母、数字字母交替、颜色交替、同心环扇形圆盘和旋转圆盘；Go/No-Go 可切换规则与 No-Go 比例；Stroop 包含颜色、方向和大小冲突；持续注意可调整节奏、目标稀有度和训练长度。用户可以直接开始正式训练，也可以自选一轮不计分练习；练习不会写入训练记录或影响自适应难度。

每次训练结束后会与同一任务最近 5 次个人记录比较，分别说明正确率和反应速度变化、可能的错误模式、难度升降原因及下一次建议。比较只用于观察个人趋势，不提供人群排名或诊断结论。

训练难度使用最近 3 次表现组成滚动窗口，同时参考正确率、反应时、漏答、误按和反应波动。连续 2 个窗口稳定达标才升级，连续 2 个窗口明显困难才降级；升级后有 2 次保护期。四类任务分别改变方格与干扰、刺激速度与规则、目标稀有度与间隔、冲突比例与作答时限等具体参数。

“专注”页支持自由专注与番茄钟两种模式。自由专注可设置 1～180 分钟；番茄钟采用 25 分钟专注、5 分钟短休息，每完成 4 个番茄进入 15 分钟长休息。两种模式都支持 30 秒开始准备、刷新恢复、系统时间校准、提前结束原因、分心分类与停车场。活动中的专注状态单独保存在本机，重新打开页面后可以继续。

“进度”页支持近 7 天、近 30 天和全部三个范围，包含行动洞察、训练活动热力图、四类任务的正确率/反应时/等级曲线、漏答与误按统计，以及现实专注的时长、完成度、主观专注感和分心次数趋势。本周目标、周总结和行动洞察均由本地固定规则计算，不调用网络服务。

阶段复测采用时间与训练量结合的本地提醒：默认满 28 天且至少 8 次训练时建议复测；高频用户满 20 次训练且至少间隔 21 天时提醒；低频用户 42 天后仍会收到提示。14 天内手动发起会保存为“快速检查”。初始基线、正式复测和快速检查与日常训练分开保存，进度页会并列雷达图、显示变化量，并根据设备、输入方式、睡眠、疲劳、环境和中断情况提示可比性及练习熟悉效应。

## 本地运行

需要 Node.js 20.19+ 或 22.12+、Python 3.9+。当前开发环境使用 Node.js 24 和 Python 3.9。

```bash
npm install
npm run dev:api
```

另开一个终端启动网站：

```bash
npm run dev
```

如果本机尚未安装检索服务依赖，先运行：

```bash
python -m pip install -r server/requirements.txt
```

首次使用向量与重排模式时下载固定版本的本地模型（约 230 MB）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/download_retrieval_models.ps1
```

引用式 RAG 的上下文预览无需 AI 平台或 API Key。项目已按 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/zh-cn/) 接好 `https://api.deepseek.com/chat/completions`、Bearer 鉴权和 JSON Output；默认模型为 `deepseek-v4-flash`，可通过环境变量更改。

启动后端和网站后，在“设置 → DeepSeek 安全凭据”输入一次 Key。Key 由本机后端使用 Windows DPAPI 按当前 Windows 用户加密，明文不会进入源码、浏览器存储、应用数据备份或 API 响应；以后使用普通 `npm run dev:api` 启动即可自动读取。只有主动替换或删除时才需要再次操作。

以下入口仍可用于同时指定模型和 API 地址，但不会再要求终端重复输入 Key：

```bash
npm run dev:api:deepseek
```

该命令用于替代普通的 `npm run dev:api`，两者不要同时运行。也可以参考 [`.env.example`](.env.example) 显式设置后端进程环境变量；环境变量会在该次启动中覆盖持久化凭据。不要使用 `VITE_` 前缀，也不要把真实 `.env` 提交到 Git。

生产构建：

```bash
npm run build
```

自动化测试：

```bash
npm test
npm run test:api
npm run eval:retrieval
npm run eval:retrieval:real
npm run eval:retrieval:vector
npm run eval:retrieval:calibrate
npm run eval:retrieval:ablation
npm run eval:generation:real
```

真实生成评测需要先在设置页保存 DeepSeek Key；命令只读取本机 DPAPI 密文，报告不会记录 Key。已冻结的 0.4.4 报告见 [`artifacts/evals/0.4.4-generation-real-eval.md`](artifacts/evals/0.4.4-generation-real-eval.md)。

构建结果位于 `dist/`。

## Windows 桌面程序

直接构建并打开桌面程序：

```bash
npm run desktop
```

仅打开已经构建好的桌面程序：

```bash
npm run desktop:open
```

生成 Windows 安装版和免安装便携版：

```bash
npm run desktop:dist
```

输出文件位于 `release/`。安装版会创建桌面和开始菜单快捷方式；便携版无需安装即可运行。

第一版本地构建尚未配置商业代码签名证书，因此 Windows SmartScreen 可能显示“未知发布者”。自用时可核对文件来源和 SHA-256 后运行；公开分发前应购买并配置 Windows 代码签名证书。

## 数据与边界

- 训练、专注、待办、笔记与设置继续使用浏览器 `localStorage`；TXT、Markdown、DOCX、文字型 PDF 的提取正文、授权和文本块使用独立的 IndexedDB v2，不需要账号或服务器。
- DOCX/PDF 的原始二进制文件不会保存；扫描型 PDF 当前没有 OCR 能力，复杂多栏 PDF 的读取顺序取决于文件文字层。
- “设置”页支持导出应用数据 JSON、导入恢复、导出 CSV 和二次确认清空。
- JSON 备份可以在浏览器版与桌面版之间手动迁移训练、专注、计划、待办、笔记和设置；当前不包含 IndexedDB 中的知识库文档。
- 数据格式当前为 v10；应用会自动迁移旧版状态，为旧雷达图建立初始基线，并尽量把旧版初始测评任务从日常训练中分离。v8 的“稍后任务”会自动并入行动便签收集区；v10 在保留 v9 待办、启动回合、现实专注及关联标识的基础上，新增独立笔记集合。
- 可在设置页调整每日投入目标、默认专注时长、提示音、界面动画、训练提示和专注完成通知，并管理个人知识来源、查看文本处理状态与分块结果。
- 桌面程序与浏览器网站使用不同的本地数据空间，网页中的历史记录不会自动迁移到桌面程序。
- 在设置页确认清空设备数据时会同时清除知识库；清除浏览器站点数据也会清除训练记录与本地知识来源。
- BM25 请求无状态；只有用户明确点击“构建本地索引”后，已授权文本块和 512 维向量才会保存到本机 Qdrant。语料变化会触发增量更新，用户可随时在实验台清除索引。
- BGE Embedding、Qdrant 和多语言 Cross-Encoder 均在本机 CPU 运行；模型缺失时界面会说明并降级。只有用户明确点击“生成引用回答”后，本次问题与界面已预览的最小证据才会发送给 DeepSeek；本地构建、检索和预览不会出站。
- 当前分数是任务表现指数，不是医学诊断、人群百分位或“脑年龄”。
- 网站不用于诊断或治疗 ADHD 等注意障碍。
