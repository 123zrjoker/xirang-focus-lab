# 0.6.0 桌面端一体化实施计划

> 规划日期：2026-09-14
> 前置版本：0.5.2
> 状态：本机候选版已完成，待独立干净 Windows 用户环境最终验收
> 说明：原 0.6.0“个人行动实验”已取消，本版本改为桌面端一体化。

## 1. 目标

把当前需要分别启动 Vite/Electron 与 Python FastAPI 的开发形态，收口为可安装、可恢复、可诊断的 Windows 桌面应用。用户不需要预装 Python、创建虚拟环境或执行命令；现有 RAG、Agent 审批、SQLite 恢复、DPAPI 凭据和 Evaluation Harness 的安全边界不得回退。

## 2. 实施顺序

### 0.6.0-a 运行时与数据边界冻结（已完成）

- 盘点 Electron、FastAPI、Python/模型依赖及当前安装包结构。
- 定义服务可执行文件、动态或受控端口、健康检查、启动超时、日志格式和错误分类。
- 定义开发、安装、便携版三种模式下的用户数据、Checkpoint、凭据、模型缓存和日志目录。
- 冻结 Electron 与渲染进程获取 API 地址的最小 IPC 契约；不向页面暴露 Node 能力或明文密钥。

### 0.6.0-b Electron 服务进程监督（已完成）

- Electron 启动本机 API，等待健康检查通过后再开放依赖 AI/RAG 的功能。
- 处理端口冲突、重复实例、启动超时、服务异常退出和应用退出。
- 提供可理解的“服务启动中 / 可用 / 降级 / 失败”状态与诊断入口。
- 验证服务重启后，0.5.1/0.5.2 可兼容 Checkpoint 仍能恢复到审批点。

### 0.6.0-c Python 服务与依赖打包（已完成）

- 选择并冻结 Windows sidecar 打包方案，产物不得依赖系统 Python。
- 将服务端代码和必要依赖纳入安装包，并验证 ASAR 外部资源路径。
- 明确本地检索/重排模型是随包提供、首次下载还是显式可选；每种路径都要有哈希校验、进度和失败恢复。
- 保持离线 Fake/规则路径与真实 DeepSeek 路径的身份标识，不能把替身显示成真实模型。

### 0.6.0-d 数据生命周期与恢复（已完成）

- 统一 Electron 用户目录与服务端目录解析，升级时保持稳定。
- 扩展备份清单，覆盖业务数据与知识库数据；设备内待审批/待执行 Agent 线程不做跨设备迁移，避免在状态修订不同的设备上恢复陈旧 Mutation Intent。
- DPAPI 密钥不进入明文备份；跨 Windows 用户恢复时明确要求重新授权密钥。
- 对导入冲突、旧版本数据、损坏备份和部分恢复建立失败关闭与回滚策略。

### 0.6.0-e 安装包与干净环境验收（本机安装链路完成；干净环境待执行）

- 生成 NSIS 与 Portable 候选产物并记录 SHA-256。
- 在干净 Windows 用户环境验证安装、首次启动、服务探活、知识检索、Agent 审批、保存计划、启动专注和重启恢复。
- 验证二次启动、单实例、正常退出、异常退出、卸载和用户数据保留/清除边界。
- 执行前端测试、API 测试、生产构建和 Fake Agent Eval；真实 DeepSeek 保留集只在显式授权时运行。

## 3. 明确不做

- 不实施个人行动实验、实验分组、基线/干预窗口或主观反馈采集。
- 不增加 Agent 写权限或跨会话隐式长期记忆。
- 不在本阶段加入扫描 PDF OCR、手写识别、XLSX、云同步或多用户。
- 不以桌面打包为理由降低审批、幂等、凭据脱敏或引用校验标准。

## 4. 完成定义

1. 新用户安装后无需命令行即可完成一次引用式问答和一次 Agent 人工审批闭环。
2. 关闭并重开应用后，业务数据、知识库和兼容 Checkpoint 均可按定义恢复。
3. 服务故障、端口冲突和模型不可用都有可观察状态，不造成静默数据损坏。
4. 备份恢复不泄露明文密钥，跨用户限制有明确提示。
5. 干净 Windows 验收记录、安装包哈希和复现步骤齐全。
6. `npm test`、`npm run test:api`、`npm run build` 与 `npm run eval:agent` 全部通过。

## 5.1 当前验收状态

- 完成定义 1：自动化门禁分别覆盖引用问答、Agent 审批、保存计划与启动专注；unpacked/Portable 已验证内置服务和模型可用。仍需在干净 Windows 上执行一次串联人工验收。
- 完成定义 2：SQLite 服务重启恢复、前端 v11 数据迁移与完整知识库备份恢复均有自动化覆盖；跨设备不迁移待审批 Agent 线程是明确的失败关闭边界。
- 完成定义 3、4、6：已通过本机测试和候选包烟雾测试。
- 完成定义 5：候选包、SHA-256、Setup 静默安装/启动/卸载自动化与复现命令已齐；独立干净 Windows 用户环境的人工业务闭环和数据保留验证尚未执行，不能用当前开发机结果替代。

详细证据见 `artifacts/evals/0.6.0-desktop-acceptance.md`。
