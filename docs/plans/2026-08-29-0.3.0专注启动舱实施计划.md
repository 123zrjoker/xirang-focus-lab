# 息壤 0.3.0「专注启动舱」实施计划

> 对应设计：`docs/design/2026-08-29-0.3.0专注启动舱设计.md`

> 实施状态：0.3.0 核心范围已完成；个人配方、主题路径和成长景观按设计保留到后续版本。

## 阶段 0：可恢复基线

- 创建包含源码、配置、锁文件、说明和当前构建产物的版本归档。
- 计算 SHA-256，并验证归档可读取且包含 `src` 与 `package.json`。
- 记录开发前生产构建基线。

## 阶段 1：规则和数据模型

- 在 `src/types.ts` 增加启动回合、候选任务、热身结果、稍后任务和专注上下文字段。
- 将 `AppState` 升级为 v8。
- 新建 `src/lib/taskSelection.ts`，实现纯函数评分、排序和推荐理由。
- 新建 `src/lib/launchFlow.ts`，实现草稿、默认值、状态转换和热身推荐。
- 扩展 `src/lib/storage.ts` 的迁移、解析、活动启动保存与清除。
- 更新完整备份与 CSV 导出。

## 阶段 2：启动舱界面

- 新建 `LaunchPage`，实现入口选择、明确任务、多任务选择、推荐确认和启动设置。
- 新建 `LaunchWarmup`，实现视觉启动、反应抑制启动、跳过和自动完成。
- 为启动流程增加输入校验、返回、取消和草稿恢复。
- 在 `styles.css` 中增加响应式样式与减少动画兼容。

## 阶段 3：应用集成

- 在 `Page` 中增加 `launch`。
- 在 `App.tsx` 中维护待启动上下文、完成启动回合并连接到 FocusPage。
- 扩展 `FocusPage` 参数、活动状态与最终 `FocusSession` 保存字段。
- 首页主入口改为“我现在就要开始”，测评作为次入口。
- 今日页增加“启动一件事”和两条场景入口。
- 进度页增加本周启动回合、完成回合和平均启动阻力的基础摘要。

## 阶段 4：验证

- 增加规则、迁移与状态测试。
- 执行 TypeScript 严格编译与 Vite 生产构建。
- 启动或复用 `http://127.0.0.1:5173`。
- 依次验收明确任务、多任务推荐、覆盖推荐、跳过热身、完成热身、刷新恢复和保存关联。
- 检查原有训练、测评、直接专注、趋势与导入导出没有回归。

## 阶段 5：文档与交付

- 更新 README 和 0.2 接续说明，记录 0.3.0 已完成范围、v8 迁移和验证结果。
- 记录仍未实现的个人配方、主题路径和成长景观。
- 提供备份位置、SHA-256、构建结果和主要文件入口。
