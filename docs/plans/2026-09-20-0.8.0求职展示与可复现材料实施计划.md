# 0.8.0 求职展示与可复现材料实施计划

> 规划日期：2026-09-20
> 前置版本：0.7.0
> 状态：本地冻结验收通过，待远端发布
> 阶段目标：把已经冻结的工程事实整理成招聘方能快速理解、无私人数据可复现、并且不会夸大产品效果的一组公开材料。

## 1. 固定边界

- 0.8.0 不新增核心产品功能，不改变 Agent Prompt、工具权限、审批语义、数据所有权或 Mutation Intent 契约。
- 对外数字必须能回链到已提交的评测、性能、安全或桌面验收报告；报告与展示文案发生冲突时，以冻结报告为准。
- 默认复现路径只使用合成数据和 Fake Agent Eval，不要求 DeepSeek Key，也不产生模型调用费用。
- 真实 DeepSeek 保留集只作为已有证据展示；重新运行必须由操作者显式授权付费调用。
- 演示数据不得包含真实姓名、联系方式、凭据、本机绝对路径、私人笔记或真实行为记录。
- 所有质量指标都描述固定数据集或同类设备上的工程结果，不推断真实用户效果，不宣称改善注意力或行动能力。
- 当前版本已统一为 0.8.0；只有远端分支 CI 通过后才创建并推送 `v0.8.0` 标签。

## 2. 实施批次

### 0.8.0-a 证据与信息架构（已完成）

- 建立 `docs/portfolio/README.md` 作为招聘方唯一入口，并提供 10 分钟、30 分钟两条阅读路径。
- 建立证据索引，把检索、生成、Agent、性能、安全、桌面验收的对外口径链接到冻结报告。
- 建立运行时架构图与数据边界说明，区分浏览器业务数据、本机服务数据、只读模型和显式出站数据。
- 整理关键技术决策、失败模式与修复证据，避免只展示最终成功结果。

### 0.8.0-b 脱敏演示与可复现入口（已完成）

- 提供可导入的 v11 合成备份、合成知识文档和逐步演示说明。
- 提供不需要 API Key 的 Fake Agent Eval 与质量门禁复现命令。
- 增加 `npm run portfolio:check`，检查材料完整性、相对链接、演示数据标记、图源一致性、本机路径和疑似密钥泄露。
- 将公开材料检查加入 `quality:gate`，防止后续代码变化造成材料失效。

### 0.8.0-c 演示视频与项目成品（已完成）

- 演示视频经执行前评估，完整录制、旁白/字幕、剪辑与逐帧隐私检查预计超过用户设定的 1 小时时间上限，本阶段按明确条件不执行。替代证据为已校验演示脚本、现有产品截图和全新数据空间自动走查。
- 仓库内通用项目描述保留为已有参考材料；用户明确本阶段不修改或编写简历，个人简历不作为 0.8.0 冻结条件。
- 一页式作品集 PDF 已从同一证据索引取数，并通过单页 A4、内容覆盖、占位符、样式、密度、字体与逐页视觉检查。

### 0.8.0-d 一致性验收与冻结（本地已完成）

- 在版本统一为 0.8.0 后，已执行 `npm run portfolio:check`、`npm run quality:gate` 和 `npm run quality:security`，当前均通过。
- 已在一次性 Electron 浏览器分区中导入演示备份和知识文档，并显式授权合成笔记。结果为 v11 状态、2 个知识来源、2 条授权和 5 个文本块，隐私扫描无发现。
- 核对 README、架构图、演示脚本、通用项目描述和冻结报告中的名称、数字、边界与版本一致。
- 已更新路线图、版本号和阶段验收报告；提交、远端 CI 与 `v0.8.0` 标签属于后续发布动作。

## 4. 完成定义

1. 招聘方可从一个入口在 10 分钟内理解问题、架构、关键安全边界、代表性指标和已知限制。
2. 在没有私人数据、没有 DeepSeek Key 的环境中，可以导入合成样例并运行 Fake Agent Eval。
3. 架构图、复现说明、演示脚本、通用项目描述和冻结报告使用同一名称与数字。
4. 公开材料不包含本机绝对路径、凭据、私人数据、未证实用户效果或无法追溯的性能数字。
5. 演示视频仅在总耗时不超过 1 小时时制作。本阶段已按用户条件豁免，并以合成数据自动走查和截图替代。个人简历修改与编写不在本阶段范围内。
6. 版本已统一为 0.8.0，`portfolio:check`、完整质量门禁与安全门禁全部通过；远端 CI 通过后才允许创建 `v0.8.0` 标签。
