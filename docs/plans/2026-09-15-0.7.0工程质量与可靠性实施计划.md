# 0.7.0 工程质量与可靠性实施计划

> 规划日期：2026-09-15
> 前置版本：0.6.0
> 状态：已完成
> 阶段目标：把已可运行的桌面端收口为可持续回归、可诊断、可审计且具备明确性能边界的工程基线。

## 1. 固定边界

- 不改变 0.5.x 已冻结的 Agent Prompt、工具权限、审批语义和 Mutation Intent 契约。
- CI 默认只运行 Fake Agent Eval，不自动触发需要密钥和费用的真实 DeepSeek 保留集。
- 诊断接口只返回版本、运行模式、进程和路径健康信息，不读取或返回密钥、用户正文、Prompt、Checkpoint 内容。
- 0.7.0 不新增产品功能；缓存与后台任务只优化既有检索、索引和 Agent 执行，不扩大数据或写权限。
- 当前 Windows 环境已用于关闭 0.6.0；独立干净 Windows 复验继续作为 0.9.0 发布候选门禁。

## 2. 实施顺序

### 0.7.0-a 发布质量门禁与 CI（已完成）

- 新增统一 `quality:gate`，串行执行前端、Electron、API、生产构建、Fake Agent Eval 和 API 性能门禁。
- 新增 Windows GitHub Actions 工作流，固定 Node 22 / Python 3.11，缓存键覆盖直接与传递依赖清单。
- 无论门禁成功或失败，都保留 Eval、性能与安全报告，便于定位回归。
- 真实 DeepSeek 保留集继续要求本机凭据和 `--allow-paid-api`，不进入普通 CI。

### 0.7.0-b 生命周期、并发与诊断（已完成）

- Electron sidecar 的 start/stop/restart 使用单一生命周期队列，避免重启与退出竞态。
- sidecar 日志改为 JSONL，至少包含时间、事件、PID、端口、启动方式与退出信息。
- FastAPI 新增 `/api/diagnostics`，返回非敏感运行时和数据目录健康信息。
- Agent 共享图与 SQLite Checkpoint 的 HTTP 操作使用进程内互斥锁串行化；新增并发回归测试。
- 保持 SSE 流期间的图操作互斥，避免同一全局图连接发生交错写入。

### 0.7.0-c 性能、缓存与后台任务边界（已完成）

- 已建立隔离数据目录的 API 微基准，测量 health、diagnostics 和 100 文本块 BM25 查询的 P50/P95/max。
- 当前硬门槛：health P95 ≤ 250 ms、diagnostics P95 ≤ 250 ms、关键词检索 P95 ≤ 500 ms。
- 已测量真实 BGE 首次/热查询、向量索引构建、Cross-Encoder 冷/热重排、进程 RSS 峰值与 Agent SSE 首事件延迟。
- BGE 查询向量缓存使用 SHA-256 键、128 项内存 LRU；索引结果缓存使用实例/数据根、语料指纹、模型校验值和检索参数组成键，限制 64 项，并在索引变化、清除和关闭时失效。
- 索引同步改为受控后台任务：单任务互斥，嵌入阶段可取消，提交阶段不可中断但持续报告进度；页面刷新后可重新读取当前任务。
- 提交前写入持久化 `committing` 标记，异常写入 `failed`；服务若在提交期间退出，旧/半成品索引不会被报告为可用，下次同步可重新比对修复。

### 0.7.0-d SBOM、依赖与安全审计（已完成）

- npm 和 Python 各生成 CycloneDX JSON SBOM；原始文件由 CI 保存，不提交仓库。
- npm audit 阻断 high/critical；pip-audit 发现任何已知漏洞即阻断。
- 将 `js-yaml` 覆盖到已修复版本，并升级 FastAPI、Starlette、Torch、Transformers、Sentence Transformers 与 Hugging Face Hub。
- 升级后执行 `pip check`、66 项 API 回归、真实 512 维 BGE 编码和 ONNX reranker 烟雾测试。
- Markdown 审计摘要必须同时记录工具退出码与漏洞数，禁止仅凭工具运行成功放行。

### 0.7.0-e 资源基线与版本冻结（当前 Windows 环境已完成）

- 已完成 0.7.0-c 的缓存、后台任务和资源占用测试。
- 已全量重建 PyInstaller sidecar，并重建 unpacked、NSIS 和 Portable 0.7.0 产物；整体烟雾、安装/卸载与退出回收回归全部通过。
- 已冻结 0.7.0 性能、安全、Eval 和桌面验收报告，并记录 sidecar、Setup、blockmap 与 Portable SHA-256。
- 只修复阻塞工程门禁的问题，不在冻结批次加入新的产品功能。

## 4. 完成定义

1. `npm run quality:gate` 与 `npm run quality:security` 均通过，且 CI 远端至少成功运行一次。
2. 并发请求、应用退出/重启、SSE 流与 SQLite Checkpoint 不发生交错写入、重复副作用或进程残留。
3. 冷/热启动、检索、索引、Agent SSE 首事件和峰值资源基线有可复现报告及回归阈值。
4. 缓存容量/失效与后台任务互斥/取消/恢复都有自动化测试和诊断状态。
5. 0.7.0 sidecar、NSIS、Portable 重新构建并通过当前 Windows 环境整体回归，哈希齐全。
6. 高危依赖、凭据泄露、审批绕过、状态冲突漏检和重复 Mutation Intent 均阻塞发布。
