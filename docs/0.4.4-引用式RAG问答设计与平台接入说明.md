# 0.4.4 引用式 RAG 问答设计与平台接入说明

## 1. 当前交付状态

0.4.4 已完成从本地混合检索到“可发送上下文”的完整代码链路，并已依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/) 实现专用适配器。2026-09-11 已通过本机安全输入临时注入 Key，并完成单样本真实 API 冒烟测试：

- `POST /api/rag/answer` 复用 BGE、BM25、RRF 与 Cross-Encoder 检索结果；
- 每条证据拥有稳定的本次请求引用号 `S1`～`S8`，同时保留来源、章节、行号和字符位置；
- 用户可以在界面中先预览问题与最小证据上下文，预览不会调用远程平台；
- Provider 测试替身只验证接口、引用和故障行为，不代表任何真实模型质量；
- 单样本成功结果只能证明真实调用和引用契约接通；完整忠实度、引用正确率与拒答评测仍需补做。

## 2. 数据流与信任边界

```text
本地 IndexedDB 知识库
        ↓ 用户明确构建
本地 Qdrant 向量索引
        ↓ Hybrid / Rerank Top-K
上下文预算与证据编号 S1…S8
        ↓ 用户先预览
用户明确点击“生成引用回答”
        ↓ 仅此时允许出站
后端 DeepSeek Provider → https://api.deepseek.com
        ↓
结构校验 + 引用白名单校验 → 界面回答与证据卡片
```

浏览器永远不读取 API Key。健康接口只报告平台是否可用、模型名和目标主机，不返回凭据。真实问题和证据只有在用户点击“生成引用回答”时才通过本地后端发送；构建索引、检索和上下文预览均留在本机。

## 3. 生成输入与上下文预算

- 最多 8 条证据；
- 全部证据正文合计最多 6,000 个字符；
- 单条证据最多 1,200 个字符；
- 超出预算的正文会明确标记为已截断；
- 知识文档中的“忽略之前指令”“系统提示”等疑似提示注入会被标记；
- 系统消息明确把所有 evidence 视为不可信事实材料，不能把其中的文字当成命令执行。

这些限制让发往平台的数据量可见、可控，也让相同输入更容易复现。

## 4. 生成输出契约

Provider 必须返回以下结构化字段：

```json
{
  "answer": "只依据证据生成的中文回答",
  "citation_ids": ["S1"],
  "uncertainties": [],
  "refused": false
}
```

后端会拒绝以下结果：

- 非拒答回答没有任何引用；
- 引用了本次证据之外的 ID；
- 返回空回答或不能解析的结构；
- HTTP、超时或响应格式异常。

证据不足时系统可直接拒答并跳过远程调用；模型也可用 `refused=true` 明确拒答并说明不确定项。

## 5. DeepSeek 接入参数

当前启用 `DeepSeekChatProvider`，保留 `CompatibleChatProvider` 作为底层抽象。根据官方文档，适配器固定使用：

- Base URL：`https://api.deepseek.com`；
- Endpoint：`POST /chat/completions`；
- 鉴权：`Authorization: Bearer <API_KEY>`；
- 结构化输出：`response_format={"type":"json_object"}`；
- 非流式请求，并为短 RAG 回答关闭思考模式；
- 默认模型：`deepseek-v4-flash`，允许通过环境变量覆盖。

可配置的后端环境变量如下：

| 变量 | 用途 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 后端专用凭据，必需 |
| `DEEPSEEK_MODEL` | 模型 ID，默认 `deepseek-v4-flash` |
| `DEEPSEEK_BASE_URL` | API 根地址，默认官方地址 |
| `DEEPSEEK_TIMEOUT_SECONDS` | 请求超时秒数，默认 60 |
| `DEEPSEEK_MAX_TOKENS` | 最大输出 token，默认 1,200 |

推荐使用以下入口启动后端：

```powershell
npm run dev:api:deepseek
```

该命令用于替代普通的 `npm run dev:api`，不能同时占用 8000 端口。脚本会在终端用隐藏输入读取 Key，只把明文临时注入当前后端进程，不写入文件。`.env` 仍已被 Git 忽略，`.env.example` 只包含占位符，而且程序不会自动加载 `.env`。

## 7. 当前不可宣称的能力

- 单样本通过不能证明模型能稳定遵守引用约束；
- 尚无完整生成质量、P50/P95 时延或成本数据；
- 未注入 DeepSeek Key 时，“生成引用回答”按钮保持禁用；
- 本版本的完成含义是工程管线和本地可审计预览完成，而不是外部模型接入完成。
