# 0.4.4 引用式 RAG 问答设计与平台接入说明

## 1. 当前交付状态

- 用户可以在界面中先预览问题与最小证据上下文，预览不会调用远程平台；

- 12 条固定集在结构合法率、拒答准确率、引用正确率、确定性忠实度代理和注入抵抗率上均达到 100%。

## 2. 数据流与信任边界

```text
本地 IndexedDB 知识库
        ↓ 用户明确构建
本地 Qdrant 向量索引
        ↓ Hybrid / Rerank Top-K
上下文预算与证据编号 S1…S8
        ↓ 用户先预览
用户明确点击“生成引用回答”
        ↓ 仅此时允许出站
后端 DeepSeek Provider → https://api.deepseek.com
        ↓
结构校验 + 引用白名单校验 → 界面回答与证据卡片
```

浏览器只在用户输入时短暂持有 API Key，并通过本地接口把它交给后端；浏览器不会把 Key 写入 `localStorage`、IndexedDB 或应用备份，也不能从后端读回明文。后端使用 Windows DPAPI 按当前 Windows 用户加密后持久化。健康与配置状态接口只报告平台是否可用、模型名、凭据来源和目标主机，不返回凭据。真实问题和证据只有在用户点击“生成引用回答”时才通过本地后端发送；构建索引、检索和上下文预览均留在本机。

## 3. 生成输入与上下文预算

- 最多 8 条证据；
- 全部证据正文合计最多 6,000 个字符；
- 单条证据最多 1,200 个字符；
- 超出预算的正文会明确标记为已截断；
- 知识文档中的“忽略之前指令”“系统提示”等疑似提示注入会被标记；
- 系统消息明确把所有 evidence 视为不可信事实材料，不能把其中的文字当成命令执行。

这些限制让发往平台的数据量可见、可控，也让相同输入更容易复现。

## 4. 生成输出契约

Provider 必须返回以下结构化字段：

```json
{
  "answer": "只依据证据生成的中文回答",
  "citation_ids": ["S1"],
  "uncertainties": [],
  "refused": false
}
```

后端会拒绝以下结果：

- 非拒答回答没有任何引用；
- 引用了本次证据之外的 ID；
- 返回空回答或不能解析的结构；
- HTTP、超时或响应格式异常。

证据不足时系统可直接拒答并跳过远程调用；模型也可用 `refused=true` 明确拒答并说明不确定项。

## 5. DeepSeek 接入参数

当前启用 `DeepSeekChatProvider`，保留 `CompatibleChatProvider` 作为底层抽象。根据官方文档，适配器固定使用：

- Base URL：`https://api.deepseek.com`；
- Endpoint：`POST /chat/completions`；
- 鉴权：`Authorization: Bearer <API_KEY>`；
- 结构化输出：`response_format={"type":"json_object"}`；
- 非流式请求，并为短 RAG 回答关闭思考模式；
- 默认模型：`deepseek-v4-flash`，允许通过环境变量覆盖。

可配置的后端环境变量如下：

| 变量 | 用途 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 可选的后端进程凭据；设置后覆盖本机持久化凭据 |
| `DEEPSEEK_MODEL` | 模型 ID，默认 `deepseek-v4-flash` |
| `DEEPSEEK_BASE_URL` | API 根地址，默认官方地址 |
| `DEEPSEEK_TIMEOUT_SECONDS` | 请求超时秒数，默认 60 |
| `DEEPSEEK_MAX_TOKENS` | 最大输出 token，默认 1,200 |

推荐先用普通入口启动后端，在设置页的“DeepSeek 安全凭据”中输入并保存一次 Key：

```powershell
npm run dev:api
```

后端新增以下本地接口：

- `GET /api/settings/ai-provider/deepseek/credential`：只返回配置状态；
- `PUT /api/settings/ai-provider/deepseek/credential`：加密保存或替换 Key；
- `DELETE /api/settings/ai-provider/deepseek/credential`：主动删除持久化 Key。

Key 被 DPAPI 加密后保存在当前用户的应用数据目录，不进入仓库，也不随“应用数据 JSON”导出。加密数据通常只能由同一台计算机上的同一 Windows 登录用户解密。也可以使用以下入口覆盖模型或地址：

```powershell
npm run dev:api:deepseek
```

该命令用于替代普通的 `npm run dev:api`，不能同时占用 8000 端口；它会自动使用设置页保存的凭据，不再提示重复输入。`.env` 仍已被 Git 忽略，`.env.example` 只包含占位符，而且程序不会自动加载 `.env`。

## 7. 结果边界

- 12 条数据为人工合成的小型固定回归集，不代表开放域、线上流量或全部攻击形式；
- “忠实度代理”是由拒答、引用集合、必要事实锚点和禁止内容组成的确定性指标，不等同于人工事实核查；
- 未保存或注入 DeepSeek Key 时，“生成引用回答”按钮保持禁用；
- Key 的 DPAPI 密文绑定当前 Windows 用户与设备，不用于跨设备同步，也不包含在应用数据备份中。
