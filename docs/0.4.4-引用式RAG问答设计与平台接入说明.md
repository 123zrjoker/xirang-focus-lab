# 0.4.4 引用式 RAG 问答设计与平台接入说明

## 1. 当前交付状态

0.4.4 已完成从本地混合检索到“可发送上下文”的完整代码链路，但没有绑定任何真实 AI 平台：

- `POST /api/rag/answer` 复用 BGE、BM25、RRF 与 Cross-Encoder 检索结果；
- 每条证据拥有稳定的本次请求引用号 `S1`～`S8`，同时保留来源、章节、行号和字符位置；
- 用户可以在界面中先预览问题与最小证据上下文，预览不会调用远程平台；
- Provider 测试替身只验证接口、引用和故障行为，不代表任何真实模型质量；
- 真实回答、忠实度和引用正确率评测，必须在用户确定平台后补做。

## 2. 数据流与信任边界

```text
本地 IndexedDB 知识库
        ↓ 用户明确构建
本地 Qdrant 向量索引
        ↓ Hybrid / Rerank Top-K
上下文预算与证据编号 S1…S8
        ↓ 用户先预览
用户明确点击“生成引用回答”
        ↓ 仅此时允许出站
后端 Provider 适配器 → 用户选定的 AI 平台
        ↓
结构校验 + 引用白名单校验 → 界面回答与证据卡片
```

浏览器永远不读取 API Key。健康接口只报告平台是否可用、模型名和目标主机，不返回凭据。真实问题和证据只有在用户点击“生成引用回答”时才通过本地后端发送；构建索引、检索和上下文预览均留在本机。

## 3. 生成输入与上下文预算

- 最多 8 条证据；
- 全部证据正文合计最多 6,000 个字符；
- 单条证据最多 1,200 个字符；
- 超出预算的正文会明确标记为已截断；
- 知识文档中的“忽略之前指令”“系统提示”等疑似提示注入会被标记；
- 系统消息明确把所有 evidence 视为不可信事实材料，不能把其中的文字当成命令执行。

这些限制让发往平台的数据量可见、可控，也让相同输入更容易复现。

## 4. 生成输出契约

Provider 必须返回以下结构化字段：

```json
{
  "answer": "只依据证据生成的中文回答",
  "citation_ids": ["S1"],
  "uncertainties": [],
  "refused": false
}
```

后端会拒绝以下结果：

- 非拒答回答没有任何引用；
- 引用了本次证据之外的 ID；
- 返回空回答或不能解析的结构；
- HTTP、超时或响应格式异常。

证据不足时系统可直接拒答并跳过远程调用；模型也可用 `refused=true` 明确拒答并说明不确定项。

## 5. 平台接入参数

当前内置 `CompatibleChatProvider` 面向常见的 chat-completions HTTP 契约。后续确定平台后，把 [`.env.example`](../.env.example) 中的参数作为启动后端进程的环境变量提供：

| 变量 | 用途 |
| --- | --- |
| `XIRANG_AI_BASE_URL` | 平台 API 根地址 |
| `XIRANG_AI_API_KEY` | 后端专用凭据 |
| `XIRANG_AI_MODEL` | 目标模型 ID |
| `XIRANG_AI_ENDPOINT` | 生成接口路径 |
| `XIRANG_AI_AUTH_HEADER` | 鉴权请求头名称 |
| `XIRANG_AI_AUTH_SCHEME` | 鉴权前缀，例如 `Bearer` |
| `XIRANG_AI_RESPONSE_FORMAT` | `json_schema`、`json_object` 或 `none` |
| `XIRANG_AI_TIMEOUT_SECONDS` | 请求超时秒数 |

`.env` 已被 Git 忽略，`.env.example` 只包含占位符。当前程序不会自动加载 `.env` 文件；这样可以避免误以为复制文件就已安全生效。实际接入时可由 PowerShell、系统环境或未来的桌面端安全凭据模块注入这些变量。

如果目标平台的请求或响应格式不同，应新增独立 Provider 适配器，而不是修改检索、上下文或引用校验层。

## 6. 接入真实平台后的验收清单

1. 使用平台文档确认 endpoint、鉴权、模型 ID、结构化输出能力和计费边界；
2. 新增脱敏的 Provider 请求/响应契约测试；
3. 检查健康接口、浏览器网络日志、错误信息和 Git 历史均不泄露 Key；
4. 对正常问题、无依据问题、冲突证据和恶意指令文档做最小真实评测；
5. 记录回答忠实度、引用正确率、拒答准确率、结构合法率、P50/P95 延迟和单次成本；
6. 全部通过后再把 0.4.4 标记为“真实生成链路完成”。

## 7. 当前不可宣称的能力

- 尚未证明任何真实模型能稳定遵守引用约束；
- 尚无真实生成质量、时延或成本数据；
- 未配置平台时，“生成引用回答”按钮保持禁用；
- 本版本的完成含义是工程管线和本地可审计预览完成，而不是外部模型接入完成。
