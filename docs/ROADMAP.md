# 息壤 AI Agent 应用工程路线图

> 完成目标：形成可由招聘方复现、可量化评测、具备隐私边界、人工审批、失败恢复和完整业务闭环的 AI Agent 应用工程项目。

## 当前基线

- 当前版本：0.7.0 工程质量与可靠性（实施中）；0.6.0 已按当前 Windows 开发机的自动化、整体烟雾和安装/卸载结果完成阶段验收，独立干净 Windows 复验保留到 0.9.0 发布候选门禁。
- 已完成：个人知识库、混合检索与引用式 RAG、Python 3.11、LangGraph 状态图、SQLite Checkpoint、Interrupt/Resume、人工审批、状态冲突检查、幂等 Mutation Intent、SSE 进度，以及独立 Agent Evaluation Harness、兼容矩阵、故障注入与真实 DeepSeek 保留集。
- 当前边界：Fake Eval 15 条与 DeepSeek 保留集 5 条均使用脱敏合成行动快照，只能证明固定分布下的工程与安全基线，不代表开放域用户质量或行动效果。产品继续只展示可追溯的个人记录与工程指标，不宣称 Agent 改善了用户行动效果。

## 实施顺序

1. **0.4.3.1 基线冻结（已完成）**：状态文档、完整备份、Git 基线与复现检查。
2. **0.4.4 引用式 RAG 问答（已完成）**：Provider 接口、DPAPI 凭据持久化、上下文预算、结构化回答、来源引用、拒答、注入防护和四类真实生成评测均已完成并冻结。
3. **0.5.0 Agent Foundation 与个人行动上下文（已完成）**：迁移 Python 3.11，加入 LangGraph 只读状态图和自研 Harness 骨架，生成可预览、可选择、带样本边界的结构化行动快照；把现有检索管线作为只读工具接入。
4. **0.5.1 有状态 AI 周计划闭环（已完成）**：SQLite Checkpoint、Interrupt/Resume、结构化草案、依据与假设、采用/修改/放弃、批准后的幂等 Mutation Intent，以及流式执行进度。
5. **0.5.2 Agent Harness 与双层 Evaluation Harness（已完成）**：完成模型、Prompt、工具、权限、校验、Trace 和评测统一接口；在现有 Retrieval Eval 外新增工具选择、参数、轨迹、任务、恢复、安全、延迟与成本评测。
6. **0.6.0 桌面端一体化（已完成）**：由 Electron 管理本机 API 服务、运行时和退出生命周期，统一模型、密钥、Checkpoint、日志与用户数据目录；代码、自动化门禁、NSIS/Portable 候选包及当前 Windows 环境的 unpacked、Portable、Setup 安装/卸载验收均已通过。
7. **0.7.0 工程质量与可靠性（实施中）**：已建立 Windows CI、SBOM、依赖安全审计、结构化诊断、Electron/Agent 并发保护、两级有界查询缓存、可取消索引后台任务，以及 API/SSE/真实本地模型/资源性能基线；下一步重建 0.7.0 桌面产物并完成版本冻结回归。
8. **0.8.0 求职展示与可复现材料**：公开脱敏样例、架构图、演示脚本与视频、技术决策记录、失败案例、指标报告和简历项目描述。
9. **0.9.0 发布候选版**：冻结数据和 API 契约，完成旧数据迁移、离线/降级路径、安装/卸载/升级、无障碍与全链路回归，修复阻塞发布的问题。
10. **1.0.0 正式发布**：完成最终用户验收，生成可安装产物、版本标签、变更记录、复现说明与发布哈希。

原计划的“个人行动实验”阶段已于 2026-09-14 取消，不再收集实验同意、基线/干预窗口或主观实验反馈，也不作为求职版 1.0.0 的完成条件。现有行动洞察可以继续描述本地历史记录，但不得升级为因果结论。

## 后续完成定义

### 0.6.0 桌面端一体化（已完成）

- 应用启动时自动拉起并探活本机 API，异常退出可诊断，关闭应用时能有序停止子进程。
- 安装包不依赖用户预先配置 Python、虚拟环境或手动执行命令。
- DPAPI 密钥、SQLite Checkpoint、模型缓存、日志和前端本地数据使用明确且稳定的用户目录；升级不能静默丢失数据。
- 导出与恢复覆盖业务数据和知识库元数据/正文；密钥、可重建向量索引和设备内待审批 Agent 线程不进入跨设备备份。SQLite Checkpoint 在同一 Windows 用户的稳定数据目录内跨服务和应用重启恢复。
- 当前 Windows 开发机已完成安装、首次启动、API/模型探活、退出回收和卸载验收；独立干净 Windows 的业务串联复验作为 0.9.0 发布门禁保留，不阻塞本阶段关闭。

### 0.7.0 工程质量与可靠性

- 冻结启动、检索、Agent 流式执行的延迟和资源占用基线，并对缓存、后台任务和并发行为建立自动化测试。
- CI 自动执行前端测试、API 测试、构建、Fake Agent Eval、依赖审计和安全门禁；真实付费评测仍需显式授权。
- 生成 SBOM 和可复现依赖清单，高危依赖、凭据泄露、审批绕过、重复副作用均阻塞发布。

### 0.8.0 求职展示与可复现材料

- 招聘方可按照一份入口文档，在无私人数据的情况下运行演示和 Fake Eval。
- 架构图、关键决策、失败与修复案例、指标边界、演示视频和简历描述彼此一致，不夸大真实用户效果。

### 0.9.0 发布候选版

- 数据/API 契约冻结；旧版本升级、备份恢复、离线降级、安装卸载和关键无障碍路径通过验收。
- 完整回归只允许修复发布阻塞问题，不再加入新的核心功能。

### 1.0.0 正式发布

- 发布候选版无阻塞缺陷，安装包、版本标签、变更日志、复现命令与 SHA-256 哈希齐全。

扫描 PDF OCR、手写识别、XLSX、云同步和多用户能力不阻塞求职版 1.0.0。

0.5.x 的详细职责边界、状态图、数据契约、评测指标和完成定义见 [`0.5-Agent-Harness与LangGraph融合设计.md`](./0.5-Agent-Harness与LangGraph融合设计.md)。

## 0.4.4 固定边界

- 代码先按平台无关方式实现，不要求现在提供 API Key。
- 浏览器只在输入表单中短暂持有密钥且不落盘；后端使用 Windows 当前用户 DPAPI 加密持久化，状态接口不回显明文。
- 离线替身只用于开发、测试和演示降级，不能伪装成真实模型。
- 真实平台接入后必须新增契约测试和最小真实评测，再宣称生成链路完成。

## 0.5.x 固定边界

- LangGraph 负责状态流转、Checkpoint、Interrupt/Resume 和 Streaming；不替代现有 Provider、RAG 或业务存储。
- 自研 Agent Harness 负责模型、Prompt、工具、权限、预算、校验、Trace 和评测入口。
- 前端仍是待办、计划和专注数据的数据所有者；后端只接收用户可预览的最小快照，并在批准后返回幂等写入意图。
- 0.5.x 只实现 thread-scoped 状态；不允许模型静默写入跨会话长期记忆。
- 不同时引入 CrewAI、AutoGen 等第二套 Agent 编排框架。
