# 息壤 AI Agent 应用工程路线图

> 完成目标：形成可由招聘方复现、可量化评测、具备隐私边界、人工审批、失败恢复和完整业务闭环的 AI Agent 应用工程项目。

## 当前基线

- 当前版本：0.4.4（已完成，下一版本为 0.5.0）。
- 已完成：个人知识库、文档解析、可追溯切块、BM25、BGE + Qdrant、RRF、Cross-Encoder、100 条人工标注查询与独立保留集评测，以及引用式 RAG 的上下文预算、结构化输出契约、来源校验、拒答、注入标记和 DeepSeek 真实生成评测。
- 当前边界：12 条合成固定集真实评测全部通过，是可重复的小型回归基线，不代表开放域或线上质量；Agent 状态图、Checkpoint、人工审批、Trace 与 Agent Evaluation Harness 从 0.5.x 开始实施。

## 实施顺序

1. **0.4.3.1 基线冻结（已完成）**：状态文档、完整备份、Git 基线与复现检查。
2. **0.4.4 引用式 RAG 问答（已完成）**：Provider 接口、DPAPI 凭据持久化、上下文预算、结构化回答、来源引用、拒答、注入防护和四类真实生成评测均已完成并冻结。
3. **0.5.0 Agent Foundation 与个人行动上下文**：迁移 Python 3.11，加入 LangGraph 只读状态图和自研 Harness 骨架，生成可预览、可选择、带样本边界的结构化行动快照；把现有检索管线作为只读工具接入。
4. **0.5.1 有状态 AI 周计划闭环**：SQLite Checkpoint、Interrupt/Resume、结构化草案、依据与假设、采用/修改/放弃、批准后的幂等 Mutation Intent，以及流式执行进度。
5. **0.5.2 Agent Harness 与双层 Evaluation Harness**：完成模型、Prompt、工具、权限、校验、Trace 和评测统一接口；在现有 Retrieval Eval 外新增工具选择、参数、轨迹、任务、恢复、安全、延迟与成本评测。
6. **0.6.0 个人行动实验**：用户主动选择、可撤销调整、前后变化对比且不宣称因果。
7. **0.7.0 桌面端一体化**：服务进程、模型生命周期、密钥安全、知识库导出恢复和干净 Windows 安装验收。
8. **0.8.0 工程质量**：缓存、后台任务、性能、并发、CI、依赖与安全审计。
9. **0.9.0 求职包装**：公开样例、架构图、演示视频、技术决策、失败案例和简历材料。
10. **1.0.0 正式发布**：全链路用户验收、可安装产物、版本标签、变更记录与发布哈希。

扫描 PDF OCR、手写识别、XLSX、云同步和多用户能力不阻塞求职版 1.0.0。

0.5.x 的详细职责边界、状态图、数据契约、评测指标和完成定义见 [`0.5-Agent-Harness与LangGraph融合设计.md`](./0.5-Agent-Harness与LangGraph融合设计.md)。

## 0.4.4 固定边界

- 代码先按平台无关方式实现，不要求现在提供 API Key。
- 浏览器只在输入表单中短暂持有密钥且不落盘；后端使用 Windows 当前用户 DPAPI 加密持久化，状态接口不回显明文。
- 离线替身只用于开发、测试和演示降级，不能伪装成真实模型。
- 真实平台接入后必须新增契约测试和最小真实评测，再宣称生成链路完成。

## 0.5.x 固定边界

- LangGraph 负责状态流转、Checkpoint、Interrupt/Resume 和 Streaming；不替代现有 Provider、RAG 或业务存储。
- 自研 Agent Harness 负责模型、Prompt、工具、权限、预算、校验、Trace 和评测入口。
- 前端仍是待办、计划和专注数据的数据所有者；后端只接收用户可预览的最小快照，并在批准后返回幂等写入意图。
- 0.5.x 只实现 thread-scoped 状态；不允许模型静默写入跨会话长期记忆。
- 不同时引入 CrewAI、AutoGen 等第二套 Agent 编排框架。
