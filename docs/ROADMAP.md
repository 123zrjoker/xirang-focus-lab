# 息壤 AI 应用工程路线图

> 完成目标：形成可由招聘方复现、可量化评测、具备隐私边界和完整业务闭环的 AI 应用工程项目。

## 当前基线

- 当前版本：0.4.4（平台接入前状态）。
- 已完成：个人知识库、文档解析、可追溯切块、BM25、BGE + Qdrant、RRF、Cross-Encoder、100 条人工标注查询与独立保留集评测，以及引用式 RAG 的上下文预算、结构化输出契约、来源校验、拒答和注入标记。
- 当前边界：最小上下文可在界面中本地预览；DeepSeek 适配器、安全启动入口和单样本真实 API 冒烟测试已完成，但尚未进行完整生成质量评测。

## 实施顺序

1. **0.4.3.1 基线冻结（已完成）**：状态文档、完整备份、Git 基线与复现检查。
2. **0.4.4 引用式 RAG 问答（DeepSeek 真实链路已接通）**：Provider 接口、上下文预算、结构化回答、来源引用、拒答、注入防护和真实 API 冒烟测试已完成；待完成多类型真实生成评测后冻结标签。
3. **0.5.0 个人行动上下文**：生成可预览、可选择、带样本边界的结构化行动快照。
4. **0.5.1 AI 周计划闭环**：结构化草案、依据与假设、采用/修改/放弃、确认后事务写入。
5. **0.5.2 生成质量与安全评测**：忠实度、引用正确率、结构合法率、无依据回答、恶意文档与故障降级。
6. **0.6.0 个人行动实验**：用户主动选择、可撤销调整、前后变化对比且不宣称因果。
7. **0.7.0 桌面端一体化**：服务进程、模型生命周期、密钥安全、知识库导出恢复和干净 Windows 安装验收。
8. **0.8.0 工程质量**：缓存、后台任务、性能、并发、CI、依赖与安全审计。
9. **0.9.0 求职包装**：公开样例、架构图、演示视频、技术决策、失败案例和简历材料。
10. **1.0.0 正式发布**：全链路用户验收、可安装产物、版本标签、变更记录与发布哈希。

扫描 PDF OCR、手写识别、XLSX、云同步和多用户能力不阻塞求职版 1.0.0。

## 0.4.4 固定边界

- 代码先按平台无关方式实现，不要求现在提供 API Key。
- 后端持有平台地址、模型名和凭据；浏览器不接触密钥。
- 离线替身只用于开发、测试和演示降级，不能伪装成真实模型。
- 真实平台接入后必须新增契约测试和最小真实评测，再宣称生成链路完成。
