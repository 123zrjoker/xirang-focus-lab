# 5 至 8 分钟演示脚本

目标是让观看者看到一条完整判断链：数据先预览，Agent 只读规划，人工批准后才生成写入意图，前端幂等应用，最后进入现实专注。不要从首页开始逐功能浏览。

## 录制前检查

- 使用全新浏览器配置或桌面测试数据目录，导入[合成演示备份](demo-data/xirang-demo-backup.json)。
- 导入并授权[合成知识文档](demo-data/focus-methods-demo.md)。
- 关闭桌面通知、聊天软件、密码管理器浮窗和显示真实用户名的终端提示符。
- 不打开凭据文件，不录制输入 Key 的过程，不展示本机绝对路径。
- 若使用真实 DeepSeek，先在录制外完成 DPAPI 保存，并明确本次调用会产生费用。
- 预先运行 `npm run portfolio:check` 和 `npm run eval:agent`，避免现场等待安装或修复环境。

## 主线

### 0:00–0:40 先讲结论

画面：项目入口或今日页。

口播要点：息壤是本地优先的注意力训练与专注启动桌面应用；本次只演示最难的工程链路，即最小数据快照、可恢复 Agent、人工审批和幂等写入。所有屏幕数据均为合成数据。

### 0:40–1:30 展示发送前快照

画面：今日页的 Agent 区域。

操作：输入“根据当前待办和近期专注状态，制定未来 7 天可执行计划”，只勾选未完成待办与近 7 天专注摘要。

必须指出：

- 页面显示将发送的类别、条数和窗口，不发送全部历史。
- 已完成待办、分心原始备注、个人笔记正文、逐题训练数据、环境变量和 Key 不进入快照。
- `baseStateRevision` 用来发现规划期间的本地数据变化。

### 1:30–2:30 展示 SSE 与只读工具

画面：生成进度与工具轨迹。

操作：启动规划，展示读取上下文、工具选择、规划、校验、等待审批等事件。

必须指出：Agent 此时只能使用三个只读工具；SSE 是执行进度，不代表模型拥有写权限。

### 2:30–4:00 展示三种审批中的“修改”

画面：计划草案与审批卡片。

操作：先说明可以直接拒绝；选择“修改计划”，把第一项缩小为 25 分钟内可完成的动作，再回到审批状态。

必须指出：修改结果会重新通过结构、待办 ID 和引用白名单校验；关闭页面或重启服务后可以凭 Thread ID 回到审批点。

### 4:00–5:20 批准、幂等写入与专注启动

画面：勾选“保存计划”和“启动第一项专注”，点击同意执行，然后进入专注准备页。

必须指出：

- 批准后后端返回 Mutation Intent，不直接写浏览器业务数据。
- 前端核验状态修订号和确定性 `actionId` 后原子应用。
- 断线重试只会得到 `already_applied`，不会重复保存或重复启动。
- 服务端收到执行 ACK 后才把线程标记为完成。

### 5:20–6:20 回到证据

画面：终端 Fake Eval 摘要或[冻结报告](../../artifacts/evals/0.5.2-agent-fake-eval.md)。

口播要点：15 条确定性用例覆盖批准前写入、审批绕过、权限拒绝、SQLite 重启恢复、旧/未来 Checkpoint、状态冲突、重复 ACK、提示注入和故障恢复；危险计数均为 0。这是工程回归，不是用户效果实验。

### 6:20–7:20 展示本地边界

画面：[运行时架构图](architecture.md)或设置页桌面服务状态。

口播要点：Electron 只管理随机回环端口上的 FastAPI sidecar；业务数据和知识库在 Renderer，本地模型与 Qdrant 在设备内，只有主动生成时最小快照或证据会发送给 DeepSeek。

### 7:20–8:00 主动讲限制

口播要点：真实 Agent 保留集只有 5 条；性能只代表冻结开发机；独立干净 Windows、代码签名和图标仍属于后续发布门禁；项目不提供医学诊断，也不宣称已改善真实用户行动效果。

## 没有 DeepSeek Key 时的诚实降级

不要把 Fake Planner 伪装成在线模型。采用以下替代结构：

1. 现场展示发送前快照和本地知识检索。
2. 用已提交的[审批截图](../../artifacts/0.5.1-agent-approval-desktop.png)讲解 UI 状态，并明确它是既有验收截图。
3. 现场运行 `npm run eval:agent`，展示审批、恢复、冲突和幂等的确定性回归。
4. 展示已冻结的[真实 DeepSeek 5 条保留集报告](../../artifacts/evals/0.5.2-agent-deepseek-holdout.md)，说明没有在本次录制中重复产生费用。

## 录制后隐私走查

- 逐帧检查是否出现 Key、邮箱、用户名、通知、本机路径、浏览器个人书签或真实历史数据。
- 字幕中的数字逐项对照[指标证据索引](evidence-map.md)。
- 视频说明写明提交版本、录制环境、合成数据和真实 Provider 是否实际调用。
- 若剪辑改变步骤顺序，字幕不得暗示未发生的实时执行。
