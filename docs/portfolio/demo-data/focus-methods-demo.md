# 合成演示资料：低摩擦专注启动

> 本文完全由项目演示目的编写，不来自真实用户，不构成医学或心理建议，也不表示方法已经通过效果实验。

## 把任务缩小成第一步

当任务显得模糊或阻力很大时，先写下一个两分钟内可以执行的动作。第一步应描述可观察行为，例如“打开文档并写下三个小标题”，而不是“把报告做好”。

## 减少开始前的环境干扰

开始专注前，把手机调为静音并放到视线以外；只保留本轮所需的一个窗口。若出现与当前任务无关的想法，先写入停车场，不立即切换任务。

## 给本轮设置完成标准

完成标准应比最终目标更小，并能在本轮结束时直接判断。例如“完成接口测试的第一个失败用例”，而不是“完成整个模块”。结束时记录一个明确的下一步，方便下次续接。
