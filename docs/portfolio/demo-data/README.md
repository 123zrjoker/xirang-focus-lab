# 合成演示数据

本目录只包含为代码审阅和录屏设计的合成内容，不来自真实用户，也不包含凭据、联系人、本机路径或私人行为记录。

## 文件

- [`xirang-demo-backup.json`](xirang-demo-backup.json)：当前 v11 / backupVersion 2 格式的业务状态，包含合成训练、现实专注、行动便签、笔记和一份已批准计划。
- [`focus-methods-demo.md`](focus-methods-demo.md)：可导入知识库的合成 Markdown 文档，用于验证授权、分块、检索和引用预览。

## 安全导入

导入备份会替换当前应用业务状态。请使用全新的浏览器配置或桌面测试数据目录；如果当前设备已有数据，先在“设置 → 数据管理”导出完整备份。

1. 启动 API 与 Vite 网站。
2. 在“设置 → 数据管理”导入 `xirang-demo-backup.json`。
3. 在“设置 → AI 与知识库”导入 `focus-methods-demo.md`。
4. 明确打开该文档的知识授权，再验证文本块与检索。
5. 数据页选择“全部”范围，因为备份使用固定参考日期，便于版本控制和复现。

## 建议演示问题

- “遇到抗拒时，怎样把任务缩小成第一步？”
- “专注开始前，手机应该怎样处理？”
- “什么时候应该记录下一步？”

文档故意只包含三条简单规则，方便观察引用是否落在正确章节。它不是医学建议或经过实验验证的方法论。
