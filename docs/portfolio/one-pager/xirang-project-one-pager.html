息壤把注意力训练、现实专注、个人知识检索与 AI 周计划放进同一款 Windows 应用。核心判断是业务数据仍由前端拥有，用户先预览最小快照，Agent 审批前只读，批准后只返回可核验、可重放的写入意图。

把模型波动隔离在写入边界外

  • SQLite Checkpoint 支持 Interrupt/Resume，三种审批均进入持久状态。
  • baseStateRevision 阻止过期计划写入。
  • 确定性 actionId 与 ACK 阻止网络重试产生重复副作用。

用冻结证据证明工程约束

  • BM25、BGE、RRF 与 Cross-Encoder 在本机执行。
  • 云端只接收用户主动发送的最小证据或行动快照。
  • Windows CI 覆盖测试、Fake Eval、性能、安全审计与 SBOM。
证据边界：所有分数都来自固定合成数据集或冻结 Windows 环境，不代表真实用户效果，也不等于开放域安全保证。架构、失败案例、报告与无 Key 复现命令见 docs/portfolio/README.md。
