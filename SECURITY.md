# Security Policy

## Supported versions

The latest GitHub Release is the only version that receives active security fixes. Please reproduce a report against that version when possible.

## Reporting a vulnerability

Please use the repository's **Security → Report a vulnerability** flow to submit a private report. Do not include exploit details, credentials, personal data, or an unpatched vulnerability in a public Issue or Discussion.

Include the affected version, operating system, reproduction steps, expected and observed behavior, impact, and any suggested mitigation. Maintainers aim to acknowledge reports within 7 days and provide an initial assessment within 14 days; complex fixes may require additional time.

The project will coordinate disclosure after a fix or mitigation is available. If the private reporting entry is unavailable, contact the repository owner first without publishing technical details.
