覆盖升级使用升版前由同一兼容代码构建的受控 0.8.0 基线，而不是重新下载公开标签产物。索引指纹为 `cdca795d1ad2c43f92534d13032459496c2cbec2a8f9972d51f07b5712c73d9e`；Agent 图版本为 `0.5.2-evaluation-v1`。DPAPI 只保存合成占位值，没有使用或输出真实 API Key。

安装层对渲染器数据的断言验证的是同一 Electron 用户数据目录及其标记未被覆盖安装或卸载删除；业务 `localStorage` 旧状态的迁移与未来版本失败关闭由前端单元测试和 `qa:accessibility` 隔离烟测验证，不把目录保留等同于所有界面数据语义均已人工走查。
