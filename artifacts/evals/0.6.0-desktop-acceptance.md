## 数据与安全边界

- Electron preload 保持 `sandbox: true`、`contextIsolation: true`、`nodeIntegration: false`，只暴露服务状态、重启和本机 API 地址。
- API 只允许绑定 `127.0.0.1`/`localhost`；Electron 每次启动选择空闲非特权端口。
- `%LOCALAPPDATA%\Xirang` 保存 DPAPI 密文、SQLite Checkpoint、向量索引和日志；安装目录内模型只读。
- 完整 JSON 备份覆盖应用状态与 IndexedDB 知识库，不包含 DeepSeek Key、可重建向量索引和待审批/待执行 Agent 线程。
- Checkpoint 在同一 Windows 用户和稳定数据目录内跨服务重启恢复；0.5.1 兼容状态允许恢复，未知未来版本失败关闭。

## 尚未通过的外部验收门禁

当前机器没有 Windows Sandbox 或可用 Hyper-V VM，开发机安装结果不能证明“干净 Windows”条件。正式冻结 0.6.0 前，需在没有本项目源码、Python、Node 和既有 `%LOCALAPPDATA%\Xirang` 的独立 Windows 用户或虚拟机中完成：

1. 核对安装包 SHA-256，安装并首次启动。
2. 完成一次知识导入、引用问答、Agent 同意/修改/拒绝、保存计划和启动专注。
3. 在审批点重启服务与应用，确认同一线程恢复；验证二次启动单实例。
4. 导出并恢复完整 JSON，确认业务与知识库数据；确认 Key 和待审批线程未跨设备迁移。
5. 卸载后确认程序文件、快捷方式与用户数据保留/人工清理边界。

完成这五项并把环境与结果追加到本文件后，才可把 0.6.0 从“候选版”标记为“已完成”。
