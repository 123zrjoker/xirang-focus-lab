## 证据边界与已知限制

- 验收在当前 Windows 10 / Python 3.11.9 环境和隔离合成数据中完成，不代表所有 Windows 设备与开放域用户数据均已覆盖。
- Setup、Portable 与 unpacked 主程序未做 Authenticode 代码签名，Windows SmartScreen 可能显示未知发布者提示。
- 当前安装包约 467.54 MiB、Portable 约 597.87 MiB，主要来自随应用分发的 Python、Torch、ONNX 和本地检索模型运行栈。
- PyInstaller 构建中的 `tensorboard`、`tzdata`、SciPy 可选模块与 Linux `libgomp` 告警未阻断 Windows 运行；sidecar、三种桌面形态和升级链路均已实机通过。
- electron-builder 当前使用默认 Electron 图标；不影响功能与数据兼容，但属于分发层视觉限制。
- 未创建 GitHub Release，也未上传本机二进制；是否公开分发需另行授权。
